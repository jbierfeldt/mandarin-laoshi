# Mandarin 老師
Personal Mandarin study player (no-build PWA). Open `#/` for the lesson index, `#/lesson/<id>` for a lesson.
Each lesson is `lessons/<id>/lesson.json` + `lessons/<id>/audio/*.mp3`, listed in `lessons/index.json`.
Generated by mandarin_kit/app_convert.py; docs in mandarin_kit/APP.md. Personal study notes. Audio belongs to its respective owners.
